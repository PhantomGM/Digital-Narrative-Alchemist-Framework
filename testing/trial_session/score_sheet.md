# DNA Trial Score Sheet

Use this for your first ugly-but-real trial run.

## Scoring rule
Score each category as:
- `1` = pass
- `0` = fail

Add one short note describing what broke.

## Categories
- **Routing** — Did it choose IC vs OOC correctly?
- **Consistency** — Did it contradict known facts or prior state?
- **In-Character Fidelity** — Did it stay in the right voice/persona?
- **Usability** — Was the response usable for play?
- **Mechanical Restraint** — Did it avoid inventing unsupported consequences?

## What to look for
### Common failures to watch
1. Narrative agent breaks character
2. OOC answer appears inside immersive prose
3. Specialist or narrative layer invents unsupported facts
4. State continuity breaks
5. Player-facing prose leaks system/planner language

### After first run
Write down the top 3 recurring failures and only fix those first.
